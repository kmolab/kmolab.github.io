MDE

Mission-Driven Education (使命驅動教育)

使命驅動教育（Mission-Driven Education）是一種以特定願景、核心價值及社會目標為核心的教育理念。有別於傳統以考試或升學為主導的模式，教育方式強調培養學生對社會、環境及群體的責任感，讓學習成為實踐個人與團隊使命的過程。

CK Design

Concept-Knowledge Design Theory

概念與知識設計理論

C-K Theory 的核心在於定義「概念 (Concept)」與「知識 (Knowledge)」的互動：

概念 (Concept)：存在於「未知的空間」，包含看似荒謬或不合邏輯的創新假設。

知識 (Knowledge)：存在於「已知的空間」，是可以被驗證、具備邏輯的既定事實。

C-K Theory 在 AI 時代的三個關鍵優勢：

駕馭 AI 的擴散力：生成式 AI 擅長在「知識空間」中進行排列組合，但 C-K Theory 強調的「跨界概念映射 (Mapping)」能指導設計師向「未知空間」提問，避免陷入 AI 產生的平庸化設計。

確保系統的邏輯性：現代產品變得日益複雜，創新必須具備可追溯性與正當性。利用 C-K Theory，工程師能有邏輯地拆解並定義設計空間，引導 AI 進行「可解釋的」最佳化。

凸顯原創與意圖：AI 的執行速度極快，但在缺乏人類「意圖 (Intent)」的情況下，產出的多樣性往往缺乏靈魂。C-K Theory 能幫助創作者釐清真正的設計方向。

C-K 理論用於建構下一代 AI 的提示詞工程（Prompt Engineering）與 RAG（檢索增強生成）架構。

下列研究將 C-K 理論代入大語言模型的 Agents 架構中。證明 AI 可以自主執行 C-K 理論的邏輯封閉迴路(當概念在知識庫為假，則修改參數；當非真非假，則將其演變為全新概念空間)。這對自動化 AI 工業設計有指標性意義。

Babylonian Square Root:

def BabylonianAlgorithm(number):
    if(number == 0):
        return 0;

    g = number/2.0;
    g2 = g + 1;
    while(g != g2):
        n = number/ g;
        g2 = g;
        g = (g + n)/2;

    return g;
print('The Square root of 0.3 =', BabylonianAlgorithm(0.3));

Publish

出版是內容管理過程中重要的一環,  無論是一段文句, 一個零組件, 一張圖片或影片, 在 html 網際環境編輯之後, 要如何轉為各種類比與數位的出版品格式, 就是此地要探討的重點.

段落文字在網際環境可以利用 Html5 加上 css 或 bootstrap 等前端框架加以處理, 最終與圖片及影片或數學方程式, 可以透過 Pandoc 將 html 轉為  Markdown 之後, 再加上手工編輯處理後, 轉為 pdf 或其他數位格式.
